# The_Shadows_Within-_A_B5_Legacy---Webpage
A modular PHP & HTML web interface set in the Babylon 5 universe. Features a secure session-based enrollment grid (Registration/Login) and an integrated custom textadventure with multple endings running with Java on an SQLite DB operations inside gamplay non-profit fan project.
I want to create something special to honor Babylon 5 and its legacy that changed television forever and especially in fact, that it was the first show with it's own internetpresence back 1994.
To create a web-page that tells you a new story and gives you the choice to make it your own (seven diferent endings so far)!
I'm a proud member of the Sci-Fi-Community and this is for all of you out there, may valon be with you ^^
